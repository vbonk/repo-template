# Getting Started

Determine repository mode first.

- In `vbonk/repo-template`, use `docs/GETTING-STARTED.md` as the source-template guide and report the relevant validation/security commands.
- In a template-derived repository that still carries generic template instructions, use `docs/PHASE-0.md` as the first-agent procedure before project-specific work.
- In an already initialized project repository, follow the project's current README and agent instructions rather than re-running template setup.

Do not start the former Quick/Full interactive setup interview merely because the repository was created from the template.
